# 0001 — Four rules rulings for cases silent in the 2012 rulebook

The 2012 Love Letter rulebook is silent on four edge cases; we adopt the AEG-later-editions / Board Game Arena consensus so play is unambiguous and matches what players expect online. Implement these as named rules; don't relitigate them.

1. **Full tie** at round end (equal hand value *and* equal discard totals) → **all tied players get a token**.
2. **Countess after a King trade** → discard **immediately**.
3. **Guard self-targeting** → **disallowed**.
4. **2-player Prince empty-deck draw** → the **single face-down burned card** (face-up removed cards are never drawn).
